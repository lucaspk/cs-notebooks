# Bibliotecas de matemática discreta
discrete.js expõe as regras básicas por IIFE (DiscreteLab) e module.exports.
explore.js acrescenta parsing validado, equivalência, domínio explícito de funções, provas ilustradas, grafos e contagem.
Carregue discrete.js e explore.js antes de model.js; os modelos dos capítulos adaptam a mesma API sem duplicar as regras.
No Node, use node --test math_disc/lib/*.test.js math_disc/capitulos/*/model.test.js.
