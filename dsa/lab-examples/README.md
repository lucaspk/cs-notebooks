# Referências de laboratório
Abra index.html para consultar checklist, cálculo, tabela e simulação por passos.
model.js contém somente domínio; configs.js descreve entradas/saídas; app.js monta os componentes.
A interface inclui rótulos, resultados anunciados e layout responsivo. Nenhum teste automatizado usa navegador.
Para reaproveitar, adapte modelo, configuração, exemplo e testes ao fenômeno do capítulo. Os dados de quantidade/preço são demonstrações de infraestrutura.
Execute node --test model.test.cjs para conferir as regras de domínio.
