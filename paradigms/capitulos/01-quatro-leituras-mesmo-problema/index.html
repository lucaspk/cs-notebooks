Quatro leituras

Objetivo: Comparar leituras de código mantendo a mesma especificação.

Pré-requisitos: nenhum capítulo anterior; os conceitos necessários são apresentados nesta página.

Antes de começar

Conceitos para o experimento

O mesmo cálculo pode ser expresso por um loop imperativo (atualiza acumulador), uma dobragem (combina cada item com o acumulado), reduce (API de combinação de uma coleção) ou um pipeline de operações (valores passam por etapas). As quatro leituras deste lab representam a mesma soma; não são quatro linguagens nem uma classificação exaustiva de paradigmas.

Exemplo trabalhado

Para [1,2,3,4], começando em 0, o acumulador percorre 0→1→3→6→10. Em cada leitura o operador é soma e a ordem dos itens é preservada, portanto o total é 10.
